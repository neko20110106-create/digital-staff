# 電子スタフ

手動操作型の電子スタフWebアプリです。スマートフォン・タブレット・PCのブラウザで利用できます。

## アプリ
- **運転画面:** https://neko20110106-create.github.io/digital-staff/
- **設定・スタフ編集:** https://neko20110106-create.github.io/digital-staff/settings.html

## 主な機能
- 列車番号・種別・行先・路線情報の表示
- 駅名、着時刻、発時刻、停車・通過の編集
- 出発・停車・到着・通過などの手動操作
- 遅延時間の設定
- 駅名切り替え、発車・停車時の枠の発光、経過時間の数字切り替えアニメーション
- アニメーション全体のON/OFFと、各アニメーション個別のON/OFF設定（初期設定はすべてON）
- 表示する駅数の設定
- 駅データのJSON入出力、CSV入出力（Excelで編集可能）
- 設定データのブラウザ内保存

## データとプライバシー
- 入力した列車情報や駅データは、利用しているブラウザのローカルストレージに保存されます。
- このアプリ自体は、入力データを開発者のサーバーへ送信する機能を備えていません。
- 表示設定、アニメーション設定（全体設定・個別設定）、遅延設定もブラウザのローカルストレージに保存されます。
- 保存データは同じブラウザ内で利用するもので、端末間で自動同期されません。
- ブラウザのデータ削除やプライベートブラウズの利用などにより、保存内容が消える場合があります。必要に応じてJSONでバックアップしてください。
- 個人情報や他人に知られたくない情報は入力しないでください。

## 重要な注意
本アプリは個人制作の趣味・シミュレーション用ツールです。実在の鉄道会社・鉄道事業者とは関係ありません。表示される列車情報・駅名・時刻はサンプルまたは利用者が入力したものであり、実際の運行情報を示すものではありません。

**実際の鉄道運行、乗務、運転取扱い、保安装置の代用には絶対に使用しないでください。**
